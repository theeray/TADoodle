# TADoodle attribution and scope

TADoodle is a new static React/Firebase implementation inspired by the core scheduling workflow of Timeful (https://timeful.app/), whose source is at https://github.com/schej-it/timeful.app.

The Timeful reference was reviewed at commit d1338f82db7654cad15f9928fc5f64fd716b078e. Timeful's Vue/Go/MongoDB application was not copied into this project. This is not a complete fork or an exact clone; the scheduling, interface, and Firebase integration here are new code. It is not affiliated with or endorsed by Timeful.

The supplied TADoodle SVG logo is included as an original asset. The display copy changes only the viewBox to remove surrounding whitespace; all paths and colors are preserved. No Timeful marks or artwork are used. Third-party packages retain their respective licenses.
